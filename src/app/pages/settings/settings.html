💡 說明指南：如何取得 Client ID？

  1. 前往 Google Cloud Console 並建立或選擇專案。
  2. 在 API 和服務 > 憑證 中，點擊「建立憑證」並選擇「OAuth 用戶端 ID」。
  3. 應用程式類型選擇「網頁應用程式」，並在「已授權的 JavaScript 來源」中加入您的本地開發 URL（例如：http://localhost:4200）。
  4. 建立完成後，複製產生的「用戶端 ID」貼回上方輸入框。
